## R001 · register_table · development

M8P515：把 B5 配成输出之后仍拉不出有力的高电平，只设方向位够吗？手册还要求哪个上拉位，怎样说明高电平驱动能力？

知识点：`open_drain`

- **R001-E1**：IOB5 输出高需 PUB[5]=1，高电平由上拉电阻提供，驱动能力弱。（M8P515@2.03 / §6.2 / PDF 23,24）

回答检查：给出 PUB[5]=1 和上拉供高电平的条件。

关键错误：把 IOB5 当普通推挽输出。
