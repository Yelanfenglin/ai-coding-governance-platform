# 嵌入式编程助手

**面向 MCU 模块开发和芯片迁移的本地 Agent。**

查规格、定位源码、修改工程、读取检查反馈，交付可审阅、可撤回的改动。
通过指标、日志与 Trace 追踪任务运行，治理模型与检索故障，并持续优化输入用量。

![系统架构](docs/images/architecture.svg)

## 运行观测与优化

**Prometheus / Grafana 指标告警 · Loki 日志 · OpenTelemetry / Phoenix 调用追踪**

| 工程问题 | 已实现的机制 |
|---|---|
| 任务变慢或卡住 | 记录任务、模型、工具与 RAG 耗时，拆分首事件与首字延迟，按 `trace_id` 定位具体调用 |
| 外部调用连续失败 | 对空响应、超时和断流分类处理；有限重试、指数退避、依赖级熔断与半开单探测 |
| 服务与检索异常 | 监控依赖就绪、检索降级、入库队列及主机资源，配置服务、任务与熔断告警 |
| 输入用量增长 | 按实际请求统计缓存与未缓存输入、推理用量和重试终局，用同题对照验证符号检索与上下文优化 |

[查看观测链路、排障路径与实现](docs/observability.md)

## 开发与交付

- **规格与源码定位**：按型号、版本取证，用 C 符号检索找到定义和引用。
- **检查反馈修复**：独立检查把真实错误返回模型，ADC 操作序列可缩减为可重放反例。
- **可撤回交付**：保存修改前内容；撤回前检查整轮文件，保护后续修改。
